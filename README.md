# Kuvempu Kavi Mane Heritage

A frontend project showcasing the life, legacy, and heritage of Kuvempu.

## 🌐 Live Website
https://vaishu-dev-tech.github.io/kuvempu-kavi-mane/

## 📌 Features
- Clean homepage with Kuvempu introduction
- Heritage page with detailed information
- Gallery with uniform images
- Responsive design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 📖 About
Kuvempu was the first Kannada writer to receive the prestigious Jnanpith Award. His work "Sri Ramayana Darshanam" is widely respected.
